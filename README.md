# valut

Сервис забирает курсы валют с сайта ЦБ РФ (`XML_daily.asp`) и поддерживает
таблицу `exchange_rates` в актуальном состоянии. Каждые 20 минут
перепроверяется окно из 8 дат (от «сегодня − 6» до «завтра»); для каждой валюты
пишутся две строки: `CUR → RUB` и обратная `RUB → CUR`.

Курс берётся из поля `VunitRate`, то есть уже за одну единицу валюты —
номинал (`Nominal`) ЦБ учитывает сам.

## Переменные окружения

| Переменная          | Обязательна | По умолчанию | Описание                                        |
| ------------------- | ----------- | ------------ | ----------------------------------------------- |
| `POSTGRES_USER`     | да          | —            | Пользователь БД                                 |
| `POSTGRES_PASSWORD` | да          | —            | Пароль БД                                       |
| `DB_HOST`           | да          | —            | Хост БД                                         |
| `DB_PORT`           | да          | —            | Порт БД                                         |
| `POSTGRES_DB`       | да          | —            | Имя базы                                        |
| `CURRENCIES`        | нет         | `USD,EUR`    | Список валют через запятую, например `USD, EUR, KZT` |
| `RUST_LOG`          | нет         | `info`       | Уровень логирования (`env_logger`)              |

Значение `CURRENCIES` читается **один раз при старте**, поэтому изменение
списка требует перезапуска сервиса. В образе `.env` отсутствует (он в
`.dockerignore`) и `ENV` в `Dockerfile` не объявлены — переменные задаются
рантаймом (compose / k8s / `docker run -e`). Если `CURRENCIES` не задана,
сервис работает со списком `USD,EUR`.

`CURRENCIES` разбирается терпимо: пробелы и пустые элементы отбрасываются,
коды приводятся к верхнему регистру, дубликаты и `RUB` (базовая валюта)
удаляются. Если в списке не осталось ни одного кода, сервис не стартует.

Валюта, которой нет в ответе ЦБ на конкретную дату, пропускается с `warn` в
логе — остальные при этом обновляются.
